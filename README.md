# Feather-Talk v2 재구현 (PWA)

참고 사이트: https://v2.feathertalk.live/

레이어로 나뉜 캐릭터 PNG를 조립해 고개 회전(가짜 3D), 눈 깜빡임, 마이크 입 움직임, 머리카락 흔들림을
주는 브라우저 전용 아바타 도구입니다. 서버 없이 동작하며, 모든 데이터는 브라우저(IndexedDB)에 저장됩니다.

원본 분석 근거와 확인 불가 항목은 [docs/ANALYSIS.md](docs/ANALYSIS.md)에 정리했습니다.
(개발 환경에서 원본에 접속할 수 없어, 사용자가 제공한 인쇄본 PDF를 근거로 했습니다.)

## 파일 구조

```
├── index.html              # 화면 구조 (헤더, 사용법, 미리보기, 레이어 목록·편집, 전체 설정, 제작자, 라이브, 확인 창)
├── style.css               # 스타일, 반응형(960px / 640px 기준)
├── script.js               # 앱 컨트롤러: 상태, UI 연결, 저장, 백업, 라이브, 겹침 표시, 서비스 워커 등록
├── js/
│   ├── renderer.js         # WebGL 렌더러: 격자 메쉬 변형(깊이·볼록·물리·눈 눌림·입 크기), 클리핑(스텐실)
│   ├── motion.js           # 고개 스프링·탄력, 호흡, 깜빡임, 입, 머리카락 관성, 마이크 입력
│   ├── store.js            # IndexedDB 저장소 (상태 JSON + 이미지 Blob)
│   └── default-character.js# 기본 캐릭터 (직접 그린 대체 그림, 11개 레이어)
├── sw.js                   # 서비스 워커 (네트워크 우선 + 오프라인 캐시)
├── manifest.webmanifest    # PWA 매니페스트
├── assets/icons/           # PWA 아이콘 (대체 아이콘)
├── render.yaml             # Render 정적 사이트 배포 설정
└── docs/ANALYSIS.md        # 원본 분석 기록
```

## 실행

서비스 워커와 ES 모듈은 `file://`에서 동작하지 않으므로 로컬 서버로 실행합니다. 빌드 단계는 없습니다.

```bash
python3 -m http.server 8080   # 또는 npx serve .
```

http://localhost:8080 접속. 마이크는 HTTPS 또는 localhost에서만 쓸 수 있습니다.

## Render 배포

1. Render 대시보드 → **New → Blueprint** → 이 저장소 선택 (`render.yaml` 자동 인식)
2. 또는 **New → Static Site** → Build Command 비움, Publish Directory `.`

## 구현된 기능

- 헤더: 사용법 열기/닫기, 백업 내보내기(JSON 다운로드), 불러오기(검증 + 확인 창), 기본 캐릭터로 되돌리기(확인 창), 라이브 시작
- 미리보기: WebGL 렌더링, 고개(마우스 따라보기 / 자동 흔들기 / 정면 고정), 표정 1~0(숫자키 지원),
  눈 감기 · 깜빡여 보기 · 입 열기 · 말해 보기, 선택한 레이어만 진하게
- 겹침 표시 끌기: 십자(얼굴 중심), 점선 원(얼굴 크기), 분홍 점선(선택한 물리 레이어의 고정선), 초록 띠(눈 영역, 위/아래 가장자리와 띠 전체)
- 레이어 목록: 선택, 보이기/숨기기, 위/아래 이동, 끌어서 순서 변경, 삭제(확인), 추가(부위 메뉴), 복제, 태그 표시
- 레이어 편집: 이름, 이미지(끌어다 놓기 / 주소 / 파일 선택, 정사각형·크기 불일치 경고, CORS 오류 안내),
  언제 보일까요(항상/눈 뜰 때/눈 감을 때/입 다물 때/입 열 때), 머리/몸, 표정별 표시, 깊이, 볼록/오목,
  흔들림 물리, 클리핑, 깜빡일 때 통통
- 전체 설정: 얼굴 중심/크기, 회전 강도 3종, 탄력, 호흡, 입 움직임, 눈 눌림 효과. 슬라이더 더블클릭 시 기본값
- 자동 저장(IndexedDB)과 저장 상태 표시, 새로고침 후 유지, 쓰이지 않는 이미지 정리
- 라이브: 전체 화면 표시, 자동 깜빡임, 마이크 소리로 입 움직임(잡음 자동 보정), 숫자키 표정,
  Esc · 종료 버튼 · 브라우저 뒤로 가기로 종료, 마이크 거부 시 안내
- PWA: 설치 가능, 오프라인 실행

## 대체·추정한 부분

- 기본 캐릭터: 원작 그림은 사용 권한이 불분명해 직접 그린 대체 캐릭터 사용
- 아이콘: 원본 아이콘 미확인 → 대체 아이콘
- 색상: 인쇄본에서 배경색이 빠져 활성 버튼·슬라이더 트랙 색은 추정
- 데스크톱 2단 배치, 레이어 추가 메뉴 항목, 라이브 화면 구성: 추정 (docs/ANALYSIS.md 참고)

## 미구현 · 확인 필요

- 유튜브 · 치지직 · 가이드 링크: 주소를 확인하지 못해 링크를 걸지 않음
- `/beta` (몸 레이어 흔들림): 미구현
- 원본 백업 파일과의 호환: 원본 형식을 몰라 보장하지 않음
- 원본과 화면을 나란히 놓고 비교하는 작업: 원본 접속이 안 돼 못 함

## 백엔드

필요 없음. 원본도 서버 없이 동작합니다. 외부 이미지 주소는 해당 서버가 CORS를 허용해야 쓸 수 있습니다.
