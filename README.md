# Feather-Talk v2 재구현 (PWA)

[Feather-Talk v2](https://v2.feathertalk.live/)의 정식판 편집기(`/`)와 라이브(`/live`)를 원본 번들 분석을 바탕으로
HTML·CSS·Vanilla JavaScript로 다시 만든 **비공식** 버전입니다. 원본 번들을 불러오거나 원본 서버에 연결하지 않고 혼자 동작합니다.

레이어로 나눈 캐릭터 PNG를 겹쳐 고개 회전(가짜 3D), 깜빡임, 마이크에 맞춘 입 움직임, 머리카락 흔들림을 주고,
라이브 화면을 OBS 등으로 캡처해 쓰는 도구입니다. 서버 없이 모든 데이터가 브라우저에 저장됩니다.

분석 근거·확인/추정 구분·미수집 자료는 [docs/ANALYSIS.md](docs/ANALYSIS.md)에 있습니다.

## 실행

빌드 단계가 없습니다. ES 모듈과 서비스 워커 때문에 `file://`로는 열 수 없고 로컬 서버가 필요합니다.

```bash
python3 -m http.server 8080     # 또는 npx serve .
```

- 편집기: http://localhost:8080/
- 라이브: http://localhost:8080/live.html (Render 배포에서는 `/live`도 됨)

마이크·카메라는 HTTPS 또는 localhost에서만 쓸 수 있습니다.

### Render 배포
Render 대시보드 → **New → Blueprint** → 이 저장소 (`render.yaml` 자동 인식, 정적 사이트).

## 파일 구조

```
├── index.html              편집기 화면
├── live.html               라이브 화면
├── style.css               공통·편집기·라이브 스타일 (원본 CSS 값 기준)
├── js/
│   ├── editor.js           편집기: 레이어 목록·속성, 전체 설정, 미리보기·겹침 표시, 백업, 사용법
│   ├── live.js             라이브: 마이크, 자동 모션, 숫자키 표정, 배경색, 프레임 제한, 웹캠 연결
│   ├── model.js            데이터 모델(원본 version 2 형식), 프리셋, localStorage·IndexedDB 저장, 백업 변환
│   ├── default-preset.js   기본 캐릭터 프리셋 (제공된 원본 백업 그대로)
│   ├── renderer.js         WebGL 렌더러 (64×64 격자 변형, 스텐실 클리핑)
│   ├── motion.js           고개 스프링, 머리카락 관성, 호흡, 깜빡임, 입, 자동 모션
│   ├── webcam.js           웹캠 얼굴 추적 (MediaPipe FaceLandmarker, 선택 기능)
│   ├── icons.js            Lucide 아이콘 (ISC)
│   └── pwa.js              서비스 워커 등록
├── assets/                 기본 캐릭터 대체 그림(원본과 같은 파일 이름), 아이콘
├── tools/                  대체 그림 생성 스크립트 (default-character.js, export-assets.mjs)
├── sw.js                   서비스 워커 (네트워크 우선 + 오프라인 캐시)
├── manifest.webmanifest    PWA 매니페스트
├── render.yaml             Render 정적 사이트 설정
└── docs/ANALYSIS.md        분석 기록
```

## 구현된 기능

**편집기**
- 상단: 사용법(처음 한 번 자동 표시, 닫기 기억), 백업 내보내기(`feathertalk-backup.json`), 불러오기, 기본 캐릭터로 되돌리기, 라이브 시작
- 미리보기: 마우스 따라보기 / 자동 흔들기 / 정면 고정, 표정 1~0, 눈 감기·깜빡여 보기·입 열기·말해 보기, 선택한 레이어만 진하게
- 끌어서 조정: 얼굴 중심 십자, 얼굴 크기 점선 원, 머리카락·장식 고정선, 눈 깜빡임 영역 띠
- 레이어 목록: 끌어서 순서 변경, 보이기/숨기기, 앞으로/뒤로, 삭제, 12종 프리셋으로 추가, 복제, 상태 배지
- 레이어 속성: 이름, 이미지(끌어다 놓기/주소/파일), 표시 조건 5종, 머리/몸, 표정별 표시, 깊이·볼록/오목, 흔들림 물리(방향·고정선·세기·탄성·출렁임), 클리핑, 깜빡일 때 통통
- 전체 설정: 얼굴 중심·크기, 회전 강도 3종, 탄력, 호흡, 입 움직임, 눈 눌림(높이·영역)
- 자동 저장(원본과 같은 `ftModel` 키, 업로드 파일은 IndexedDB), 저장 실패 시 안내, 슬라이더 더블클릭 초기화

**라이브**
- 마이크 소리로 입 움직임(민감도 조절, 말하는 중 표시), 자동 깜빡임, 마우스 따라보기 → 멈추면 자동 모션
- 리깅 강도, 자동 모션 범위, 60/30fps, 배경색(크로마키용 기본 초록), 숫자키 표정, 2초 뒤 조작 막대 숨김
- 마이크 권한 거부·장치 없음 안내

**추가 난이도 항목 (분리 구현)**
- 웹캠 얼굴 추적: MediaPipe FaceLandmarker로 고개 각도, 정면 맞추기(보정값 저장), 좌우 반전, 눈 깜빡임 따라하기. 모듈·모델은 처음 켤 때 CDN에서 받음. 카메라 권한 거부/장치 없음/모듈 다운로드 실패를 구분해 표시하고, 실패해도 마우스·자동 모션으로 계속 동작

**PWA**: 설치 가능, 한 번 연 뒤 오프라인에서 편집기·라이브 실행

## 미구현 기능과 이유
- `/beta` 전용 기능 (몸 리깅·연주 포즈, 캐릭터 슬롯 10개, 확대·이동, '고정' 부위, 그림 비율 자동 인식, 몸 레이어 흔들림) — 정식판 재현을 우선함. 백업 안의 해당 값은 지우지 않고 보존
- `/multi` 다중 캐릭터와 화면 공유(`getDisplayMedia`) — 같은 이유
- 원본 기본 캐릭터 그림 — 수집되지 않았고 사용 권한도 불분명해 대체 그림 사용 (아래 참고)
- 예전 `localStorage`(`ftBang` 등) 설정 옮기기 — 다른 주소(origin)라 옮길 데이터가 없음

## 기본 캐릭터 그림 바꾸기
`assets/`의 `bang.png, mouth.png, mouthopen.png, eyes.png, eyesclosed.png, face.png, body.png, back.png`를
같은 이름의 512×512 정사각형 PNG로 바꾸면 코드 수정 없이 기본 캐릭터가 바뀝니다.
원본 그림은 원작자에게 허락을 받은 경우에만 넣어 주세요. 대체 그림을 다시 만들려면 `npm i -D playwright` 후 `node tools/export-assets.mjs`.

## 테스트 결과 (Chromium 자동 테스트)
- 콘솔 오류 없음 (개발 환경 네트워크가 막아 생긴 글꼴·MediaPipe CDN 요청 실패, 의도한 오류 테스트 제외)
- 편집기: 사용법 닫기·재표시, 레이어 선택 시 미리보기 상태 전환, 추가·업로드·이름 변경·슬라이더 스냅·더블클릭 초기화·표정 칩·머리/몸·복제·삭제·이동·끌어서 정렬·숨기기, 잘못된 이미지 주소 오류 표시, 얼굴 중심 끌기
- 새로고침 후 레이어·설정 유지, 백업 내보내기 → 다시 불러오기(업로드 파일 복원), **제공된 원본 백업 불러오기**, 잘못된 파일 거부, 되돌리기 후 프리셋과 정확히 일치·업로드 파일 정리
- 라이브: 배경색, 가짜 마이크로 입 열림, 조작 막대 자동 숨김, 설정 유지, 마이크·카메라 없음 안내
- 모바일 375px 가로 넘침 없음, 오프라인 새로고침으로 편집기·라이브 열림

## 남은 문제·한계
- 원본과 화면을 나란히 비교하지 못함 (개발 환경에서 원본 접속 불가) — 번들 CSS 값으로 맞춤
- 실제 마이크·카메라와 MediaPipe 추적은 실기기에서 확인 필요
- 목록 끌어서 정렬은 원본처럼 HTML5 드래그라 휴대폰 터치로는 안 됨 (앞으로/뒤로 버튼 사용)
- 520px 이하에서 상단 막대 고정을 푼 것은 원본과 다름 (화면 가림 문제)
