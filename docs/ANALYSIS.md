# 원본 사이트 분석 (https://v2.feathertalk.live/)

## 분석 경로

- 개발 환경에서는 원본에 직접 접속할 수 없었음 (네트워크 정책 403, 공개 DNS 조회 실패).
- 사용자가 제공한 **인쇄본 PDF 4쪽** (`Feather-Talk.pdf`, 2026-10-20, ChromeOS Chrome 154에서 인쇄)을 근거로 분석.
- 인쇄본의 한계:
  - 브라우저 인쇄는 **배경색을 생략**하므로 버튼·슬라이더 트랙·활성 상태의 배경색은 확인 불가.
    (활성 버튼이 흐린 글자로 찍힌 점으로 미루어 "배경색 + 흰 글자" 방식으로 추정)
  - 인쇄용 1단 레이아웃만 보이므로 데스크톱 화면의 실제 단 구성은 확인 불가.
    도움말의 "오른쪽 + 레이어 추가" 문구로 미루어 **미리보기 왼쪽 / 편집 패널 오른쪽** 2단으로 추정.
  - 호버·포커스·애니메이션·모달·드롭다운의 열린 모습은 확인 불가.

## 서비스 개요

레이어로 나뉜 캐릭터 PNG를 조립해, 고개 회전(가짜 3D)·눈 깜빡임·입 움직임(마이크)·머리카락 물리를
적용하는 **브라우저 전용 PNG튜버 아바타 도구**. 원본 문구: "Feather-Talk는 별도의 서버를 운영하지 않아요",
"모든 설정은 이 브라우저에 자동 저장돼요".

## 1. 확인된 화면 및 기능 (PDF 근거)

### 헤더
- 로고 "Feather-Talk" (회색 굵은 글씨)
- 메뉴: 사용법 · 백업 내보내기 · 불러오기 · 기본 캐릭터로 되돌리기
- "라이브 시작 ▷" (파란 글씨)

### 사용법 패널 (닫기 X 있음, 하늘색 테두리 둥근 상자)
- 제목 "처음 오셨나요? 세 단계면 충분해요"
- 1 레이어 넣기 / 2 얼굴 중심 맞추기 / 3 입체감과 머리카락 (원문 그대로 재현)
- 이미지 규칙: 모든 이미지는 같은 크기의 정사각형 PNG(투명 배경), 캐릭터 전체 그림에서 해당 부위만 남긴 형태

### 미리보기
- 캐릭터 + 겹침 표시: 십자(얼굴 중심, "얼굴 중심" 라벨), 점선 원(얼굴 크기)
- 안내문: "+ 얼굴 중심 · 점선 원 얼굴 크기 · 분홍 점선 머리카락 고정선 · 초록 띠 눈 깜빡임 영역(눌림 효과를 켰을 때) — 모두 끌어서 옮길 수 있어요."
- 고개: 마우스 따라보기 | 자동 흔들기 | 정면 고정 (분할 버튼), □ 선택한 레이어만 진하게
- 표정: 1 2 3 4 5 6 7 8 9 0 (분할 버튼)
- 상태: 눈 감기 · 깜빡여 보기 · 입 열기 · 말해 보기
- "라이브에선 눈은 자동으로 깜빡이고, 입은 마이크 소리에 맞춰 움직여요."

### 레이어 목록
- 제목 "레이어", 부제 "위에 있을수록 앞에 그려져요 · 끌어서 순서 변경"
- 행: 끌기 손잡이, 썸네일, 이름, 태그(예: "이미지 없음", "몸", "장식 물리", "머리카락", "입 다물 때"), 보이기/숨기기(눈 아이콘), 위로, 아래로, 삭제
- 선택된 행은 하늘색 테두리, 숨긴 행은 흐리게 + 눈 꺼짐 아이콘
- 목록은 고정 높이 스크롤
- 하단: "레이어 추가", "복제"(복사 아이콘, 파란 테두리)

### 레이어 편집
- 이름 입력
- 이미지: "파일을 끌어다 놓기" 점선 영역, "이미지 주소 (https://...)" 입력, "내 PC에서 파일 선택"
- 언제 보일까요?: 선택 상자(확인된 값 "항상"; 본문에 "눈 뜰 때", "입 다물 때" 언급) + 머리 | 몸 분할 버튼
- 표정: 1~0 + 전체 (표정 번호별 표시 여부)
- 입체감: 깊이(뒤~앞, 기본 0), 볼록/오목(오목~볼록, 기본 0, 제목 옆 작은 파란 선 표시)
- 머리카락 · 장식: 흔들림 물리 (스위치로 추정 — 인쇄 시 체크박스가 찍히지 않음)
  - "몸 레이어의 흔들림은 베타(/beta)에서 먼저 시험 중이에요. 정식판에서는 머리 레이어만 흔들려요."
- 눈동자 옵션: □ 아래 레이어에 맞춰 자르기(클리핑), □ 깜빡일 때 통통

### 전체 설정
- 얼굴: 얼굴 중심(가로) 50%, 얼굴 중심(세로) 40%, 얼굴 크기 25%
- 고개 움직임: 좌우 회전 강도 100% (0~200), 상하 회전 강도 100% (0~200), 기울기 강도 100% (0~200), 움직임 탄력(뽀용함) 50 (차분~통통)
- 호흡: 50 (없음~크게), 4초 주기
- 눈 · 입: ☑ 입이 열리고 닫힐 때 움직임 (기본 켜짐), □ 깜빡일 때 눈이 눌리며 감기는 효과 (기본 꺼짐)
- "슬라이더를 더블클릭하면 기본값으로 돌아가요. 모든 설정은 이 브라우저에 자동 저장돼요."

### 제작자 영역
- "제작자: 연이나" 및 소개 문단, 링크: Claude, 유튜브, 치지직, 가이드, 이전 버전 사용하기(feathertalk.live)

## 2. 추가 확인이 필요한 화면 및 기능

| 항목 | 현재 구현에서의 처리 |
|---|---|
| 데스크톱 실제 레이아웃(단 구성, 폭) | 2단(미리보기 왼쪽 고정, 편집 오른쪽)으로 추정 구현 |
| 배경색·활성 버튼 색·슬라이더 트랙 색 | 하늘색 계열로 추정 |
| "라이브 시작" 화면 구성 (배경, 종료 방법, 마이크 감도 UI 유무) | 전체 화면 오버레이 + 종료 버튼/Esc, 감도 UI 없음(자동 보정) |
| "레이어 추가"의 부위 선택 메뉴 항목 | 몸/얼굴/뒷머리/앞머리/흰자/눈동자/눈꺼풀/감은 눈/다문 입/벌린 입/장식으로 추정 |
| "언제 보일까요?" 선택지 전체 | 항상/눈 뜰 때/눈 감을 때/입 다물 때/입 열 때 |
| 목록 태그 규칙("장식 물리" vs "머리카락") | 물리를 켠 레이어에 부위가 머리카락이면 "머리카락", 아니면 "장식 물리" |
| 볼록/오목 제목 옆 파란 선의 의미 | 볼록 정도를 보여주는 작은 곡선 표시로 구현 |
| 기본 캐릭터 그림 | 원작 그림은 사용 권한이 불분명해 사용하지 않고, 직접 그린 대체 캐릭터 사용 |
| 백업 파일 형식 | 확인 불가 — 자체 JSON 형식 (원본 백업과 호환 보장 안 됨) |
| /beta 경로 (몸 레이어 흔들림) | 미구현 |
| 유튜브·치지직·가이드 링크 주소 | PDF에 URL이 없어 확인 불가 — 링크 비활성 |
| 모바일 레이아웃, 호버/포커스 스타일 | 추정 구현 |

## 3. 백엔드 또는 외부 서비스가 필요한 기능

- 없음. 원본도 서버 없이 브라우저에서만 동작한다고 명시.
- 외부 이미지 주소: 해당 서버가 CORS를 허용해야 WebGL 텍스처로 쓸 수 있음.
- 마이크: 브라우저 권한(HTTPS 또는 localhost) 필요.
